📚 Scholarly Knowledge Graph (SKG) Ontology

The SKG Ontology models scholarly publications — papers, authors, venues, citations, datasets, ML methods — with provenance annotations via RDF-star. Designed for the NeurIPS Knowledge Graph pipeline.

Version 6.0.0 CC-BY 4.0 NeurIPS

SKG Core Ontology

Source-agnostic core TBox: classes and properties for scholarly works, authors, organizations, venues, topics, identifiers, and ML research semantics (tasks, datasets, methods, models, architectures).
